# Favour
一个vue3练手的游戏项目，css为主

# Vue 3 + TypeScript + Vite 项目 以下是跑项目顺序
1. npm install
2. npm run dev

3.src/asssets/text 目录下随便写，记笔记的东西

/api  后端数据
/asssets 静态资源
/components  全局组件
/constants  全局常量
/model   封装一些函数、hmlt模板 （不会调用 可取出来用 仅在需要时候复制出来使用）
/store  全局状态  vuex
/test  测试文件  （可删）
/utils  一些组件js
/views  页面
