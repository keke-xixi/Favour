# 风险&跟进

不确定的点需要记录并核对，且有结论

本次需求，会影响到其他模块、微服务的功能

测试需要注意的点

*   是否有产品易用性带来的舆情风险，比如选项无法多选，用用操作过于繁琐(待细化)
    
*   是否有二维码扫码困难带来的用户体验问题
    
*   是否有使用用户隐私信息能来的法务合格风险，比如用户的地址，人脸，定位等
    
*   是否有给推广带来不确定性服务(无法解释)造成的体验风险
    
*   是否有高投入，产出无法解释价值的风险
