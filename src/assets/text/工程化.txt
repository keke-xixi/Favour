随便聊聊

模块化在前端非常重要 、各种第三方库层出不穷、每个第三方库解决前端一部分问题、如何方便的使用呢？

1.包管理（包里面都是模块、ajax、jquery、moment... 每个第三方库可以看成是一个包）
  -- 官方的包管理器：npm
        --- 下载包的网站：https://www.npmjs.com/
        --- 下载包的命令：npm install 包名  （仅仅把包下载到当前项目的 node_modules 文件夹里，不会修改 package.json 文件）
        --- 下载包的命令：npm install 包名 --save  （安装包，并在 package.json 文件的 dependencies 字段中记录这个包及其版本号， 用于生产环境依赖）
        --- 下载包的命令：npm install 包名 --save-dev  (同上，用于开发环境依赖)
        --- 下载包的命令：npm install 包名 -g  （将包安装到你操作系统的一个全局目录下（而不是当前项目的 node_modules），使其成为一个可以在任何地方通过命令行直接调用的全局命令）

  -- 社区的包管理器：yarn、pnpm、cnpm


2.eslint 代码风格管理器、代码规范（ 在.eslintrc 配置文件来配置什么规则 ）

3.babel.config.js  
   -- 用来转换es6+的语法、es6+的语法浏览器不识别、需要转换成es5的语法

4.PostCss(工程化里面解决css问题全靠它了)
  -- 用来转换css的语法、css的语法浏览器不识别、需要转换成css的语法
  (
    js -> babel -> js
    scss -> Sass -> css
    css -> PostCss -> css
  )

5.webpack


学习路线： 模块化 -> 包管理器 -> 构建工具 -> 脚手架
