生命周期钩子	说明
onLoad	页面加载时触发（可接收 query 参数，如 onLoad(options)）
onShow	页面显示时触发（每次进入页面都会触发）
onReady	页面初次渲染完成时触发（DOM 已准备好）
onHide	页面隐藏时触发（如跳转到其他页面或进入后台）
onUnload	页面卸载时触发（如 uni.navigateBack 或关闭页面）
onPullDownRefresh	监听用户下拉刷新（需在 pages.json 中配置 "enablePullDownRefresh": true）
onReachBottom	页面滚动到底部时触发（常用于上拉加载更多）
onPageScroll	页面滚动时触发（可获取滚动距离 scrollTop）
onResize	窗口尺寸变化时触发（如旋转屏幕）
onTabItemTap	点击当前 tab 时触发（适用于 tabBar 页面）

类型	主要生命周期钩子
应用生命周期	onLaunch, onShow, onHide, onError  (App.vue)
页面生命周期	onLoad, onShow, onReady, onUnload, onPullDownRefresh, onReachBottom  (pages/xxx/xxx.vue)
组件生命周期	created, mounted, beforeDestroy
特殊生命周期	onShareAppMessage（小程序）, onBackPress（App/H5）

预处理指令	说明

例子
// #ifdef H5
console.log('这段代码只在 H5 浏览器环境执行');
// 使用 document 等浏览器 API
const element = document.getElementById('myElement');
// #endif

// #ifdef APP-PLUS
console.log('这段代码只在 App 环境执行（包括安卓和iOS）');
// 使用 uni-app 的 APP 端 API
plus.device.getInfo();
// #endif

// #ifdef APP-PLUS && OS_ANDROID
console.log('这段代码只在安卓 App 环境执行');
// 安卓专用代码
plus.android.importClass('java.io.File');
// #endif

onLoad() {
    this.initChart()

    // 监听窗口尺寸变化
    uni.onWindowResize((res) => {
        this.windowWidth = res.size.windowWidth   // windowWidth 单位px 整个手机屏幕宽度
        this.windowHeight = res.size.windowHeight  // windowHeight 单位px 整个手机屏幕高度 （包含头部标题）
        console.log('窗口变化:', res.size)
    })

    // 初始获取一次窗口尺寸
    uni.getWindowInfo((info) => {
        this.windowWidth = info.windowWidth
        this.windowHeight = info.windowHeight
    })
},
onUnload() {
    // 移除监听（避免内存泄漏）
    uni.offWindowResize()
},
