vue3中，reactive()函数创建的响应式对象，不能直接赋值给另一个变量，否则会导致响应式失效。
需要使用Object.assign()或展开运算符来更新响应式对象。
const state = reactive({ count: 0 });

// 使用 Object.assign 来更新 state 对象
state = Object.assign({}, state, { count: 1 });

// 或者使用展开运算符
state = { ...state, count: 1 };
