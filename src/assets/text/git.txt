 // 飞书上传代码步骤  （git branch  保证自己目前是在自己的功能分支上开发）
1---先用 vscode commit&push 提交代码
2--- git checkout test  切换到dev分支
3--- git pull origin test  从dev分支拉取代码到本地dev(解决冲突)
4---git checkout feat/XTWQ-9  切换到自己的开发的功能分支
5--- git merge test  合并dev分支（本地  解决冲突）
6--- git push origin feat/XTWQ-9  把自己本地的代码上传到远程 feat/XTWQ-9
7--- 然后就可以在飞书上发起合并请求了

8----- git merge origin/dev-chen 合并远程的其它分支
