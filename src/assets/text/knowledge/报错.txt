当nvm环境变量出问题：
npm config get prefix
打开“系统属性”窗口（右键点击“此电脑” -> 属性 -> 高级系统设置）。
点击“环境变量”。
在“系统变量”中找到 Path，点击“编辑”。
将 npm 全局包的路径（如 C:\Users\<你的用户名>\AppData\Roaming\npm）添加到 Path 变量中。
确认保存并重新启动命令行窗口。
